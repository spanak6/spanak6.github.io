# SPANAK · Meet the team

A minimal single-page team website using the green palette from the SPANAK pitch. Six member cards include research summaries and the supplied LinkedIn links. Initials are used instead of headshots.

## Preview

Open index.html in your browser. Everything is contained in that file; no installation, build, account keys or external fonts are needed.

## Publish on GitHub Pages

1. Create a GitHub repository (a public repository works with GitHub Free).
2. Upload index.html and .nojekyll to the top level of the repository, then commit to the main branch. Do not upload the ZIP itself.
3. Open the repository's Settings, then Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose main and / (root), then Save.
6. Once GitHub completes deployment, the Pages settings will show the website link. Deployment can take a few minutes.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit

Open index.html in a text editor. Each <article class="person"> contains one person's name, field, bio and LinkedIn URL. Update the corresponding aria-label if you change a person's name or link. Colours and responsive layouts are in the <style> block near the top.

The page adapts to three, two and one columns depending on screen width. Links open in new tabs. It includes keyboard focus styles, a skip link and reduced-motion support.
